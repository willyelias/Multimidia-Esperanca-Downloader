🖥️ Youtube Downloader Ultimate para Windows (Desktop)

Para downloads pesados em 4K 60fps, Playlists inteiras com 1 clique, conversão nativa via FFmpeg e extração automática de Cookies do Chrome/Edge/Firefox (para vídeos privados ou restritos), utilize também a versão Desktop incluída neste projeto!

  • ✅ Auto-instalação do yt-dlp e FFmpeg com barra de progresso no rodapé
  • ✅ Cookies Automáticos do Navegador (Chrome, Edge, Firefox, Brave, Opera) sem precisar exportar `.txt`
  • ✅ Recorte exato de trechos (`--download-sections`) baixando apenas os minutos desejados
  • ✅ Suporte a Playlists Completas com fila individual e miniaturas
  • ✅ Conversor Local FFmpeg com porcentagem em tempo real (MP4 H.264, MP3 192kbps, WAV)
📦 Acessar Repositório no GitHub

Como executar no PC (Python):

git clone https://github.com/willyelias/yt-downloader-ultimate.git
cd yt-downloader-ultimate
pip install -r requirements.txt
python app.py

Como gerar o executável (.exe):

pip install pyinstaller
pyinstaller --noconsole --onefile --name "YTDownloaderUltimate" app.py
